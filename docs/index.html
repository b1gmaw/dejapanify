Stop retyping
Japanese forms.

Japanese web forms accept either half-width (半角) or full-width (全角) characters, almost never both — and they rarely tell you which. dejapanify reads what each field actually wants and converts your text to match.

The problem

The same character exists twice in Unicode. A field that wants one will reject the other, and the error message looks identical to what you typed.

That last field is deliberate. Nothing on the page says which width it wants, so the extension leaves it alone rather than guessing.

It reads, it doesn't guess

Japanese forms usually state their requirement — beside the field, or in a pattern attribute. The extension collects those signals, weighs them, and acts only when they're conclusive.

SignalExampleTrust
pattern attributepattern="^[0-9]{7}$"Highest
Printed instruction「半角数字で入力してください」Very high
autocompleteautocomplete="postal-code"High
type / inputmodetype="tel"Medium
Field name and labelname="name_kana"Supporting

Waits for your IME

Never writes while a composition is in progress, so it can't corrupt what you're typing.

Undo always works

A one-click undo on every conversion, and Ctrl+Z still behaves normally.

Never touches passwords

Password, hidden, file, date and checkbox inputs are excluded outright.

Install

Looks like you're using your browser.

Firefox Not published yet

The Mozilla Add-ons listing is prepared but not yet submitted, so for now Firefox installs from source. Requires Firefox 142 or newer.

  1. Build it: git clone https://github.com/b1gmaw/dejapanify.git, then npm install && npm run build.
  2. Open about:debugging#/runtime/this-firefox.
  3. Click Load Temporary Add-on and pick dist/firefox/manifest.json.
  4. Try it with npm run demo.

A temporary add-on is removed when Firefox closes, so repeat step 3 after a restart.

Microsoft Edge Not published yet

The Edge Add-ons listing is prepared but not yet submitted. For now, follow the Chromium instructions below — Edge loads unpacked extensions the same way.

Chrome, Brave, Vivaldi, Opera Manual

Straight answer: Chrome only allows installing extensions from the Chrome Web Store, and listing there costs a one-time fee we haven't paid. So these browsers need a manual install. It takes about two minutes and you only do it once.

  1. Build it: git clone https://github.com/b1gmaw/dejapanify.git, then npm install && npm run build. Keep the folder — deleting it uninstalls the extension.
  2. Open chrome://extensions (Brave: brave://extensions).
  3. Turn on Developer mode, top right.
  4. Click Load unpacked and choose the dist/chrome folder.

Chrome will show a "Disable developer mode extensions" warning on startup. That's Chrome's standard notice for anything not installed from its store; you can dismiss it.

Another browser

dejapanify needs a browser that supports WebExtensions — Firefox, or a Chromium browser like Chrome, Edge, Brave, Vivaldi or Opera. Safari is not supported.

Checking that it works

npm run demo

This serves the test form at http://127.0.0.1:8123/demo.html. The page tells you at the top whether it can see the extension.

Use that address rather than opening public/demo.html directly. Browsers do not run extensions on file:// pages — Firefox will not inject a content script there at all, and Chrome only does so if you enable Allow access to file URLs on the extension's details page. Opened as a local file, the demo looks broken even when everything is working.

It collects nothing

Not a reassurance — a description of the code. The extension contains no fetch, no XMLHttpRequest, no WebSocket and no remote scripts. There is nowhere for anything to go.

  • No network requests
  • No analytics
  • No account
  • No telemetry
  • No remote code
  • Reproducible from source

Questions

Will it change what I meant to type?

No. It converts character width, never meaning. 山田 never becomes ヤマダ. A field it cannot confidently identify is left untouched.

Does it interfere with my IME?

No. It never writes to a field while a composition is in progress, and only converts once you've finished and moved on.

What if it gets a field wrong?

Every conversion shows a one-click undo, and Ctrl+Z works normally. You can also disable it per site, or turn off individual conversion types in the settings. If a site is consistently wrong, please report it — that's the most useful contribution.

Why does it ask to read data on all websites?

Japanese sites aren't confined to one domain, so the extension can't know in advance which pages have Japanese forms. It does nothing unless a page looks Japanese and a field identifies the width it needs. It reads and rewrites form values only, and sends nothing anywhere.

Does it work on mobile?

Firefox for Android supports extensions, so it should. It hasn't been tested there yet. iOS is not supported.
